# Attribution and scope

- Project name: Small Sounds — Insect Listening Exhibit
- This is an independent educational prototype, not an official Orcasound project.
- Conceptual inspiration: [Orcasound Ocean Listening Exhibit](https://www.orcasound.net/portfolio/ocean-listening-exhibit/)
- Related open-source project to review before any code reuse: [Orcabooth](https://github.com/orcasound/orcabooth)

The current starter was written as a new implementation and does not intentionally copy Orcabooth source. Before adapting upstream code, confirm its current license, preserve required notices, and consider opening an issue or contacting maintainers.

No third-party animal recordings are bundled. Synthetic demos must not be presented as authentic species calls. Recordings added later need documented source, permissions/license, attribution, and identification confidence.
